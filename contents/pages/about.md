## 关于 HeyBlog 项目

HeyBlog 是面向个人独立博客的发现与导航项目。项目通过整理公开站点资料、连接博客之间的友链关系，为访问者提供查找入口，也为博客站长提供收录、资料维护和状态核对渠道。

HeyBlog 由两个既有项目合并形成：

- 通过公开友链发现个人博客的原 HeyBlog 项目。
- 整理和展示个人博客列表的集博栈（zhblogs）项目。

合并后统一使用 **HeyBlog** 名称。相关合并与迁移事项见 [项目合并与迁移公告](/blog/2026080501)。

## 项目内容

HeyBlog 目前围绕以下内容开展维护：

- 整理博客名称、网址、简介、分类、订阅源等公开站点资料。
- 提供目录浏览、检索、筛选和站点详情展示。
- 通过站长提交、公开目录和公开友链发现候选博客。
- 检查站点、订阅源、站点地图和友链页面的公开可访问状态。
- 维护收录标准、数据字段说明、项目公告和相关声明。

HeyBlog 不托管第三方博客正文，也不因收录、分类、排序、统计或检测而认可、推荐或背书第三方站点。完整边界见 [免责声明](/disclaimer)。

## 成员、贡献者与项目立场

正式项目组成员是经项目沟通确认加入的人员，包括当前参与者、暂离成员和已经离开的历史成员。成员页面中的正式成员资料由项目静态维护；参与代码、文档、数据或其他协作不会自动取得成员身份。

项目合并前形成的历史贡献者致谢名单作为冻结的历史快照保留，仅在资料错误或权利请求需要时修订。当前外部贡献者展示功能启用后，仅根据 HeyBlog 相关 GitHub 仓库的公开贡献记录通过 GitHub API 自动维护。历史致谢或外部贡献记录均不表示对应人员属于项目组、拥有仓库权限或可以代表 HeyBlog。

成员在个人账号、个人博客、第三方社区或其他非正式场合发表的言论仅代表本人。只有经项目流程发布在 HeyBlog 官网、GitHub 组织仓库、官方账号中的内容，或者获得明确书面授权的对外说明，才代表 HeyBlog 的正式立场。完整治理边界见 [项目治理说明](https://github.com/heyblog/.github/blob/main/GOVERNANCE.md)。

## 收录来源

博客资料主要来自：

1. 博客站长或用户通过站点提交功能提供的资料。
2. 允许在合理范围内使用的公开博客目录。
3. 已收录博客主动公开的友情链接及其指向的公开页面。
4. 项目为核验和完善目录而进行的人工检查。

爬虫只访问无需登录即可获取的公开页面，不绕过验证码、访问控制或其他技术限制。数据来源、使用范围和退出方式分别见 [数据使用与下架声明](/data-use) 和 [爬虫与网站检测协议](/crawler)。

## 使用项目

- 查找或浏览博客：前往 [博客目录](/site)。
- 提交尚未收录的博客：前往 [站点提交](/site/submit)。
- 修订或删除已收录资料：使用对应站点维护入口，或通过邮箱说明站点地址和处理诉求。
- 了解收录标准和字段含义：前往 [项目文档](/docs)。
- 参与代码、文档或数据维护：参阅 [参与贡献](/contribute)。

本站不投放广告。收录、排序、资料修订和问题处理均以公开规则及实际核验结果为依据。

## 联系方式

普通 Bug、功能建议和其他可公开讨论的开发问题提交到对应仓库的 Issue；网站程序、页面渲染或接口问题提交到 [heyblog/web Issues](https://github.com/heyblog/web/issues)。

目录资料纠错、下架、停止抓取、隐私、版权、社区举报、安全漏洞及其他不宜公开的事项按 [支持与反馈说明](https://github.com/heyblog/.github/blob/main/SUPPORT.md) 通过对应入口或项目邮箱办理。发送邮件时，请提供相关页面或站点地址、问题说明、必要依据和希望采取的处理方式；请勿发送密码、密钥、完整身份证件或与事项无关的隐私信息。

# HeyBlog

HeyBlog 致力于发现、整理并链接个人独立博客，为博客作者和访问者提供目录、检索及维护服务。

## 项目入口

- [HeyBlog 网站](https://www.heyblog.net)
- [网站程序与服务仓库](https://github.com/heyblog/web)
- [文档、静态数据](https://github.com/heyblog/.github)

## 反馈与参与

问题反馈、功能建议、资料纠错、隐私或版权请求发送至 [contact@inbox.mail.heyblog.net](mailto:contact@inbox.mail.heyblog.net)。

安全漏洞报告请发送至 [security@inbox.mail.heyblog.net](mailto:security@inbox.mail.heyblog.net)。

新博客收录申请请通过 [站点提交](https://www.heyblog.net/site/submissions/new) 进行提交。

代码、文档和数据贡献请先阅读对应仓库的贡献说明。
